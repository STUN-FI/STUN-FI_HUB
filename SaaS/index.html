How the platform flows

Each user type starts from the correct entry point so authentication and dashboard access stay clean and secure.

Schools Register or login, then manage teachers, students, announcements, and result access.
Teachers Confirm account first, then login to enter draft scores, submit subject scores, and view school posts.
Students Confirm admission first, then login to see announcements, dashboard updates, and result access status.
